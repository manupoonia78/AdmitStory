# Fixtures

Synthetic material for the evaluation harness (spec §8.11, Appendix J). **No real person appears
here**, and none may (§0): every applicant, employer, school, number and quote is invented.

## `applicants/<slug>/`

| File                 | What it is                                                                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `profile.json`       | Who they are, how they talk, and what first run would have recorded.                                                                       |
| `ground_truth.json`  | The complete truth about this person: facts, stories, people, goals. The simulator answers only from this, and a run is scored against it. |
| `transcript_seed.md` | How this person actually speaks, in their own cadence — the simulator's style reference.                                                   |
| `resume.pdf`         | Generated, for the import path. Present for the three used by import runs.                                                                 |
| `expected.json`      | Properties a good kit must have. Phase 4, when kits exist.                                                                                 |

Phase 1 ships the first three for all twelve applicants. `resume.pdf` is generated by
`pnpm --filter @admitstory/ai fixtures:resumes`, and `expected.json` waits for Phase 4.

## `schools/`

Six sample packs. Phase 3, with the School Pack schema.

## `llm-replays/`

Recorded model responses, keyed by a hash of the request, served when `AI_MODE=replay` so CI never
touches the network (§15). Record with `AI_MODE=live` and a key in the environment.
